# StreamORT — reconstrucción

Proyecto académico en C# y .NET 8 que reconstruye StreamORT: una aplicación de consola para gestionar competencias, equipos y creadores de contenido mediante POO. Incluye persistencia CSV y pruebas xUnit.

Documentación:

- [Plan de trabajo](docs/Plan.md) y [arquitectura](docs/Arquitectura.md).
- [Clonación, compilación y distribución](docs/Submodulos-y-distribucion.md) y [ejecución de pruebas](docs/Pruebas.md).
- [Utilidades](Mis%20Librerias/Utilidades/README.md): entrada de datos, menús y consola.
- [DataBases](Mis%20Librerias/DataBases/README.md): persistencia CSV y relaciones.

Estructura: `src/` (aplicación), `docs/` (guías), `test/` (pruebas y scripts) y `test/resultados/` (evidencia).
